# Commerce JUnit Demo

This project is a small Java + Maven commerce sample that demonstrates common e-commerce business logic with JUnit 5 tests.

## Included features
- Product catalog data model
- Shopping cart with quantity rules
- Pricing calculations and discount logic
- Checkout flow with stock validation
- JUnit 5 tests for core commerce scenarios

## Project structure
- `src/main/java/com/example/commerce` – production code
- `src/test/java/com/example/commerce` – JUnit tests

## Run the tests
```bash
cd commerce-junit-demo
mvn test
```

## Notes
This is a public sample for learning and demonstration. It is not tied to a specific enterprise commerce platform like HCL Commerce, but it follows the same general domain patterns.
